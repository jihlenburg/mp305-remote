# Reference material

[Register definitions](registers/README.md) preserves ten source SVD/header
files used in the independent workspace, with original notices, source URLs
and SHA-256 hashes. They support comparison with observed register addresses;
they do not prove which chip is installed.

The WCH SDK comparison's [API map](../firmware/v51/canonical/wch-sdk-api.tsv),
[provenance](../firmware/v51/canonical/wch-sdk-reference.json) and
[Ghidra snapshot](../firmware/v51/ghidra/sdk-reference/program.json) live with
the V51 evidence. Its binary input stays outside the repository.
