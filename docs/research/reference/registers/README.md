# External register definitions

These text files are the register descriptions used by the independent
workspace. They contain no original manufacturer firmware image. The source
URLs, file sizes and hashes are recorded in [sources.json](sources.json).
They are preserved as downloaded; their notices remain intact. They are
third-party reference material and are not relicensed by the project.

The two Xiaohua C headers state BSD 3-Clause terms. The other files retain
whatever notices were present in the supplied copies; this inventory does
not assign a new license to them. Main MCU identity remains unresolved.
These definitions support comparisons and do not prove installed silicon.
