# Historical independent workspace

These are the earlier analysis outputs, scripts, symbol proposals and notes.
They are preserved for comparison and contain superseded findings. Current
results are in [the recovery record](../README.md) and its reviewed notes.
The original firmware and Ghidra databases remain outside the repository.

`notes/` adds a historical-status banner and removes an obsolete coordination
reference. Original hashes are in the workspace snapshot; untouched source
files remain in the scratchpad. The scripts retain their original paths and
behavior, including destructive import and unchecked emulator helpers. Use
the maintained recovery runners from the spike for new work.

`out/` preserves the original decompilation, references, strings, generated
register maps and logs. Register names reflect candidate SVD choices.
`report/` holds the earlier preamble. The complete report is one level up.
