# ADR-0012: Agent anonymity and ownership

- Status: Accepted
- Date: 2026-09-30
- Decided by: user
- Related: [AGENTS.md](../../AGENTS.md)

## Context

Development of this repository involves AI coding agents working on research,
design, implementation, documentation, and maintenance alongside the project
owner. Ownership and attribution stay unambiguous.

## Decision

Any AI coding agent contributing to this repository:
- Must never claim any copyright, authorship, or ownership over code,
  documentation, or any other artifacts produced for this repository. All
  rights belong exclusively to the repository owner.
- Must never state or disclose its contribution, model name, agent identity,
  or assistant brand in code, docstrings, comments, commit messages, pull
  requests, documentation, or issues (for example, no "Generated by...",
  "Co-authored-by: <agent>", or similar attribution markers).
- Must stay absolutely and completely anonymous at all times.

## Alternatives considered

- Standard co-authorship tags (for example, `Co-authored-by: <agent>`):
  rejected. Agents must remain completely anonymous.
- Permitting agent attribution in documentation: rejected. No agent branding or
  identity may appear anywhere in the repository.

## Consequences

- All contributions are made without agent attribution.
- Commit messages, documentation, code comments, and docstrings contain no
  agent mentions or generated-by notices.
- AGENTS.md records this as a mandatory rule for all participating agents.
